CRASH POINT

Provably Fair Verifier

Verify a completed round using its revealed server seed, previously published server-seed hash, client seed, and nonce.

Important: This verifier uses the example HMAC-SHA256 formula documented below. It does not prove that a third-party game uses this formula. The game operator must publish its exact algorithm and commitment before each round.

How verification works

  1. Calculate SHA-256 of the revealed server seed and compare it with the hash published before the round.
  2. Calculate HMAC-SHA256 using the server seed as the key and clientSeed:nonce as the message.
  3. Read the first 52 bits of the HMAC digest as an integer.
  4. Calculate the crash multiplier using the example 1% house-edge formula and compare it with the displayed result.

crash = max(1.00, floor(99 × 2^52 / (2^52 − h)) / 100)

All verification runs locally in your browser. The seed values are not sent to a server.
